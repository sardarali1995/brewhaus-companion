# BrewHaus Companion Files

Practice data and code for the book **AI-Powered Data Science: Automating Analytics and Machine Learning with LLMs** by Syed Sardar Ali Shah.

## What's here

| File | What it is |
| --- | --- |
| `brewhaus_customers.csv` | 5,000 customer rows from the fictional BrewHaus coffee chain. Deliberately messy, for the cleaning chapters. |
| `brewhaus_sales.csv` | Daily revenue and transactions for five stores, July 2024 to June 2026. |
| `brewhaus_companion.ipynb` | Every code example from the book, in order, with answers to the *Try It Yourself* exercises. |
| `make_brewhaus.py` | The script that generated both CSV files (optional; the files are already included). |

## Get started in Google Colab

1. Download `brewhaus_customers.csv`, `brewhaus_sales.csv` and `brewhaus_companion.ipynb` (click each file, then the download button).
2. Go to colab.research.google.com and choose **File > Upload notebook**, then pick `brewhaus_companion.ipynb`.
3. Click the folder icon on the left and upload the two CSV files.
4. Choose **Runtime > Run all**.

No sign-up beyond a free Google account is needed, and nothing needs installing.

## About the data

BrewHaus and every customer in these files are fictional. The data was generated by `make_brewhaus.py` with a fixed random seed, so it never changes between downloads.
